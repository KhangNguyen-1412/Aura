Cấu Hình Google Drive Tự Động

Tự động sao lưu ảnh & clip lên Google Drive khi tải lên Aura

●
TRẠNG THÁI HIỆN TẠI

Dán URL bạn nhận được từ Google Apps Script sau khi bấm Triển khai (Deploy) Web App.

Mã Nguồn Google Apps Script:

1. Mở Google Drive → Tạo thư mục Aura Media → Copy Folder ID trên thanh URL.

2. Mở script.google.com → Tạo dự án mới → Dán mã nguồn đã sao chép vào Code.gs.

3. Thay YOUR_FOLDER_ID ở dòng đầu bằng Folder ID ở Bước 1.

4. Bấm Deploy → New deployment → Chọn Web app → Ai có quyền truy cập: Anyone (Bất kỳ ai) → Bấm Deploy.

5. Copy Web App URL dán vào ô bên trên rồi bấm Lưu & Áp Dụng!
